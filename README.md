# 🧮 My Cal - Java AWT Calculator

A clean, responsive desktop calculator built using pure Java AWT (Abstract Window Toolkit). It supports essential arithmetic operations along with a one-click Light Mode and Dark Mode theme switcher.

## ✨ Features
* **Basic & Extended Operations:** Addition (`+`), Subtraction (`-`), Multiplication (`*`), Division (`/`), Modulus (`%`), and Square Root (`√`).
* **Theme Switcher:** Instant toggle between **Light Mode** and **Dark Mode**.
* **Utility Controls:** Clear all (`AC`), Delete last digit (`DEL`), and Decimal point support.
* **Menu Bar:** Includes File, View, Edit, and Help menu options.
* **Error Handling:** Handles invalid number formats and empty input exceptions gracefully.

## 🛠️ Tech Stack
* **Language:** Java (Core)
* **GUI Framework:** Java AWT (`java.awt`)
* **IDE:** NetBeans
